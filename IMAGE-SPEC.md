# M House — Image Spec (placeholder shot list + sizes)

One row per image slot on the site, with the exact size to export. Prepared 2026-10-09 by measuring the real rendered size of every slot at desktop (1440px) and mobile (375px).

## How to read this

• **Export size** is already 2× the largest displayed size, so images stay crisp on retina / high-DPI phones and laptops. Prepare at the size shown; do not go smaller.
• Every content image is **largest on desktop**, so the desktop size governs. The heroes are the exception: they fill the screen and must look good both wide (desktop) and tall (portrait phone), so keep the main subject **centred** with some breathing room around it.
• **Format:** JPG, sRGB colour, quality ~80. Aim for under ~400KB each (heroes can go a little higher, ~600KB). I can also batch-compress on upload if you send larger files.
• **Filenames help SEO.** Use descriptive, lowercase, hyphenated names, for example `mhouse-swim-hero-pool.jpg`, `mhouse-stay-duchess-bed.jpg`. The caption in each row is a good basis for the name and the alt text.
• The captions below come straight from the page placeholders (the `data-ph` labels), so they double as the shot list / brief for the photographer.

## Things that do NOT need a photo

• **Splash / entry screen** (`index.html`): branded gradient with the logo. No photo.
• **Logo** (nav, footer, splash): already set, licensed separately. Not photography.

## Reuse opportunities (to cut the count)

• The **3 room cards on the home page** (Shorty's, Duchess, The Bungalow) can reuse the best "the room" shot from each room's gallery on the Stay page. No need to shoot them twice.
• The **home hero slideshow** can reuse your strongest hero shots from the section pages (pool, courtyard, a room, the lounge).
• If 5 shots per room on Stay is more than you want to prepare, the galleries work fine with 3 to 4 each; tell me the count and I will adjust the page.
